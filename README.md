## 📌 About

A modern, fully responsive personal portfolio website showcasing software engineering projects and skills. Built with clean HTML, custom CSS with variables, Bootstrap for layout, and interactive JavaScript elements. Features a dark theme with gradient accents, glassmorphism effects, and smooth animations.

## ✨ Features

- **Modern Design** – Dark theme with teal and gold accent colors
- **Fully Responsive** – Optimized for mobile, tablet, and desktop viewports
- **Smooth Animations** – CSS transitions and transform effects on interactions
- **Project Showcase** – Grid layout displaying 5 featured projects with descriptions
- **Social Integration** – Direct links to GitHub, Facebook, Instagram
- **Contact Section** – Email button with working mailto functionality
- **Accessible** – Semantic HTML5, proper heading hierarchy, ARIA attributes
- **Performance** – Lightweight with custom CSS and minimal dependencies

## 📦 Installation

### Clone the repository:

```bash
git clone https://github.com/Nafiz204/Portfolio-Nafiz_Imtiaz.git
cd Portfolio-Nafiz_Imtiaz
```

### Open in browser:

Simply open `index.html` in your web browser or serve locally:

```bash
# Using Python 3
python -m http.server 8000

# Using Python 2
python -m SimpleHTTPServer 8000

# Using Node.js (with http-server)
npx http-server
```

Then navigate to `http://localhost:8000` in your browser.

## 🎨 Design System

### Color Palette
- **Background** – `#07111f` (Dark Navy)
- **Surface** – `rgba(13, 24, 43, 0.9)` (Card backgrounds)
- **Primary Accent** – `#f6b93b` (Gold)
- **Secondary Accent** – `#4ed2c9` (Teal)
- **Text** – `#e8f0f9` (Light Gray)

### Typography
- **Headings** – Space Grotesk (Bold, 600-700 weight)
- **Body Text** – Manrope (Regular, 400-500 weight)
- **Base Size** – 16px

---

## 💡 Key Features Implementation

### CSS Variables System
All colors and spacing use CSS custom properties for easy theming:
```css
:root {
  --bg: #07111f;
  --surface: rgba(13, 24, 43, 0.9);
  --accent: #f6b93b;
  --accent-2: #4ed2c9;
  /* ... more variables */
}
```

### Glassmorphism Effects
```css
backdrop-filter: blur(18px);
border: 1px solid rgba(255, 255, 255, 0.14);
background: rgba(255, 255, 255, 0.06);
```

### Responsive Grid
Mobile-first approach with breakpoints at 576px, 768px, 992px, 1200px.
